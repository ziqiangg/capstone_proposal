# Capstone Project Details

**Project Overview:**

*(Please use a separate sheet if necessary)*

This capstone project involves the research, design, and development of
an open-source AI Red Teaming tool for assessing Large Language Model
(LLM) and Generative AI applications against the OWASP GenAI LLM Top 10
(2026) risk categories.\
\
The tool will orchestrate existing open-source security testing
frameworks (e.g. Garak, PyRIT, Giskard, Inspect AI) alongside
custom-built Python attack modules to execute security test cases,
capture evidence, identify vulnerabilities, and generate reproducible,
pentest-style reports.\
\
The project addresses a capability gap within the Cyber Architecture &
Development (CYAD) division: the ability to systematically red-team
internally deployed GenAI applications without relying on paid
commercial tooling.

**Project Objectives:**

*(Please use a separate sheet if necessary)*

The candidate is expected to:\
\
1. Research and document all ten OWASP GenAI LLM Top 10 (2026)
vulnerability categories and their applicable testing methodologies.\
2. Evaluate existing open-source AI red-teaming tools (Promptfoo, PyRIT,
Garak, Giskard, Inspect AI) and recommend a technical foundation for the
project.\
3. Design and implement a modular tool architecture orchestrating
open-source frameworks and custom attack modules.\
4. Develop automated and semi-automated test modules covering all ten
OWASP LLM Top 10 categories.\
5. Build a finding-validation and evidence-capture engine that minimises
false positives.\
6. Generate professional, OWASP-mapped, reproducible pentest-style
reports.\
7. Benchmark the completed tool against existing frameworks and manual
red-teaming for accuracy and coverage.

**Industry Relevancy:**

*(Please use a separate sheet if necessary)*

As organisations increasingly deploy LLM-powered applications for
internal and public-facing use, the ability to systematically assess
these systems against known AI-specific vulnerabilities is a growing
operational necessity.\
\
This project directly supports the Cyber Architecture & Development
(CYAD) division\'s mandate to proactively secure AI systems, reducing
reliance on costly commercial AI red-teaming products and building
in-house capability aligned to an internationally recognised standard
(OWASP GenAI LLM Top 10 2026).

**Project Scope:**

*(Please use a separate sheet if necessary)*

The project covers research, architecture design, and development of an
AI red-teaming tool addressing all ten OWASP GenAI LLM Top 10 (2026)
categories, tested against a deliberately vulnerable sandbox AI
application.\
Categories requiring primarily manual review (e.g. Supply Chain) will be
addressed through documentation and process-review guidance rather than
automated attack modules.\
\
The project is limited to open-source and free technologies. Testing of
production LTA systems is a stretch goal beyond the core deliverables,
contingent on time and explicit authorisation, and is not a core
requirement of the capstone.

# Project Timeline

*(Please use a separate sheet if necessary; a Gantt chart may be
included as annex)*

The project follows an approximately 32-week plan across eight phases:\
\
Phase 1 (Weeks 1-4): Foundation & Research --- AI Security Fundamentals
Report; OWASP LLM Top 10 2026 Testing Matrix.\
\
Phase 2 (Weeks 5-8): Open-Source Tool Evaluation --- Tool Comparison
Report; Tool Evaluation Report & Demonstration.\
\
Phase 3 (Weeks 9-10): Tool Architecture Design --- System Design
Document.\
\
Phase 4 (Weeks 11-16): Minimum Viable Product --- Core Framework v0.1;
LLM01 Attack Module; LLM02/LLM08 Modules.\
\
Phase 5 (Weeks 17-24): Advanced Testing --- RAG Security, Output
Handling, Agentic Testing, remaining OWASP coverage.\
\
Phase 6 (Weeks 25-28): Detection, Evidence & Reporting --- Finding
Validation Engine; Pentest Report Generator.\
\
Phase 7 (Weeks 29-30): Validation --- Benchmark & Accuracy Report.\
\
Phase 8 (Weeks 31-32): Finalisation --- Tool Hardening; Final
Presentation & Handover.
