# SRC-01

BEACON shall provide a Curator with the means to enable and disable a source, without a code change and without removing it from the Source Set.

**Rationale.** A source that can be switched off only by deleting it loses its history. Renaming and removing a source are changes to a Governed Artefact, which the Curator makes through the means to change each Governed Artefact (GOV-17); adding one is a Curator's acceptance of an Onboarding outcome (SRC-08), which enables the source (SRC-33), and changing another Entry part of its entry is accepting a version of that entry (SRC-36). A Curator who wants an accepted source held back disables it here.
