# EVD-03

Each Evidence locator shall resolve, every time it is resolved, to the same passage of the version of the Article Record it was made from or, where that text has been erased, to the time and reason of its erasure.

**Rationale.** Without this, "findable again" is only a hope. ACQ-06 and ACQ-09 keep prior versions, so the version must be named.
