# DLV-20

IF no development qualifies for a scheduled Delivery, THEN BEACON shall send nothing and record the skipped Delivery with the reason, where an Operator can see it.

**Rationale.** An empty or padded message spends the recipient's attention for nothing; the record shows the day was skipped on purpose, not lost. The Operator sees it in OPS-07 and the digest.
