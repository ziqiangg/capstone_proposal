# DEV-07

IF an Admitted item reports an event, incident, vulnerability, announcement, research result or campaign for which BEACON holds no development, THEN BEACON shall create a development for it.

**Rationale.** An item that reports something BEACON has not seen must not be forced into the nearest existing development. A development created this way is Novel in the Cycle that creates it (TRD-05).
