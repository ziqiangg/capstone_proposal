# ACQ-22

WHEN a Collection returns an Erased item, BEACON shall retain nothing of that return but, where BEACON holds the item, its Encounter.

**Rationale.** An erasure answers a request that the item not be kept; if a later Collection kept its text and page again, the erasure would last only until the source listed the item again. The Encounter (ACQ-05) is still recorded for an item BEACON holds, since it says only that the item was returned, by which source and when. An item a Curator erased before BEACON held it has no Article Record to record an Encounter in (A-terms, Encounter), so nothing of its return is retained; the erasure's own record (ACQ-08) shows who erased it, when and why, and the item stays erased until a Curator lifts the erasure (ACQ-23).
