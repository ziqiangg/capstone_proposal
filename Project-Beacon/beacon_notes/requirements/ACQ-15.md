# ACQ-15

WHERE BEACON records an item's extracted text as empty, or as extracted from another form in which the source offers the item, because the document the item offers has no text layer or has one that cannot be read, or records it as empty because a part of the item was not obtained or its text cannot be derived from what BEACON retains of the item, BEACON shall record that reason with the extracted text.

**Rationale.** Split from ACQ-02. Where BEACON extracts no text from an item's document, or extracts it from another form, the reason says so, so that an empty or substitute text is never read as the item's own full text.
