# OPS-07

BEACON shall show an Operator, for the latest Cycle, its completeness, the sources not collected, each Stage's state, each Unfinished item and each Failed item with what its failure affected, and when its Briefing was Published, together with each re-derivation that awaits confirmation or is in progress and, for the latest Delivery, its Delivery outcomes or the reason it was skipped.

**Rationale.** If answering "is it working" means reading logs, nobody will check. Everything the Reader is never told is here.
