# CTX-09

WHEN a corpus's publisher releases a new version, or a new capture of a corpus that has no versions differs from that corpus's latest Baseline, BEACON shall record the capture as a new Baseline.

**Rationale.** Frameworks change on their own cadence. ATLAS changes monthly, and the SSP publishes no version. How versions are detected and snapshots derived is a design decision.
