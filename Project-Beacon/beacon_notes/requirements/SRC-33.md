# SRC-33

WHEN a Curator accepts an Onboarding outcome (SRC-28), BEACON shall enable the outcome's source in the Source Set as part of that acceptance.

**Rationale.** Accepting an outcome is the Curator's decision that the source is ready, so the source is enabled by it and collected from the next Cycle that starts (SRC-10). Starting it disabled would add a second step to the usual case, and asking at each acceptance would add a choice nobody needs. A Curator who wants a source held back disables it straight after accepting (SRC-01). Its first Collection is a first Collection: no possible gap is counted for it (A-terms, Health entry), and what it takes is design.
