# DEV-10

BEACON shall extract from each Admitted item the Entities it names, each with an Evidence locator.

**Rationale.** Clause (c) of the Materially new information test depends on Entities, but no other row produces them. Entity extraction is a Judgement, so EVD-01 records it.
