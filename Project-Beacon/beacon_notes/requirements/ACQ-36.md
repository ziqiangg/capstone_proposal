# ACQ-36

BEACON shall record with each version of an item's Article Record the version of each procedure that made it, the version of the Source Set entry under which it was made and, where it was made from a rendered copy of a page, the version of the renderer that made that copy.

**Rationale.** Whether a held version is current when its item returns (ACQ-30), and under what a version or a confirmation was made (ACQ-33), can be decided only if each version says what made it. A version made by a Collection was made under the entry it was collected under; one made by a Re-extraction, under the entry ACQ-32 sets. The renderer recorded is the one that made the rendered copy the version read, kept at Collection, since no Re-extraction renders a page; it is not part of a procedure's version, and ACQ-30's test of what is current does not read it. ACQ-13 and ACQ-14 record a Supplied value's procedure version for that value; this row records, for every version, whether or not it holds a Supplied value, the version of every procedure that made it and the only record of the entry version it was made under.
