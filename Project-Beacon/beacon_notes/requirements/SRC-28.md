# SRC-28

BEACON shall provide a Curator with the means to accept an Onboarding outcome that proposes a version of a Source Set entry, putting that version into effect as the source's entry in the Source Set.

**Rationale.** Giving a link starts an Onboarding but adds no source; this acceptance, made once the outcome is shown (SRC-27), is the only way a source is added (SRC-08), and it enables the source (SRC-33). One act both adds the source and puts its entry into effect, the ways of fetching its pages included (SRC-30), so no source is collected under an entry that no Curator accepted. The change to the Source Set is recorded with who made it and when, as any change to a Governed Artefact is (GOV-07).
