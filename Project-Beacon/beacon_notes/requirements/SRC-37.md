# SRC-37

WHEN a Cycle closes, BEACON shall prepare one version of a source's Source Set entry for the Drift flags on the version in force that the close raised or that are open, every preparing for them ended by BEACON's own failure (SRC-40), re-reading the Entry parts SRC-42 names on pages it reads under the whole version, holding the rest, unless no Entry part or Standing would change.

**Rationale.** A Curator answers a flag by disabling the source, keeping the flagged version or accepting a version correcting it (SRC-17), and cannot write that version by hand (SRC-36). Read on the source's pages as a whole, it gives there its Drift reference for every thing a flag may name (A-terms). One version answers a close's flags. A flag BEACON's own failure kept from one is tried again at each later close while open, so a version appears once the fault is fixed. Where nothing would change, none is prepared, and the flags' entries say so (SRC-17).
