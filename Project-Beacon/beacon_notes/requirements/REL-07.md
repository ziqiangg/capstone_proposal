# REL-07

BEACON shall provide a Curator with the means to evaluate the scope Method against the labelled evaluation set and to see the results beside [[MAX_ABSTENTION_RATE]], [[MAX_FALSE_ADMIT_RATE]] and [[MAX_MISSED_RATE]].

**Rationale.** REL-04, REL-05 and REL-06 bind an evaluation that no other row lets anyone run. The Curator owns the labelled evaluation set and the three ceilings.
