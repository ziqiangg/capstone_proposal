# UIX-02

WHEN a Reader opens the web interface, BEACON shall show the latest Published Briefing first.

**Rationale.** A reverse-chronological list is what BEACON replaces. The Briefing already holds the Recommendation Set's Accounts, in rank order, and the active trends (OUT-03).
