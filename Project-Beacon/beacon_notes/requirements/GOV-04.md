# GOV-04

BEACON shall provide a user who holds a parameter's owning role with the means to change that parameter's current value within its bounds, without a code change.

**Rationale.** Each parameter has exactly one owning role, so each such capability belongs to one role. A Method's settings are not parameters (GOV-18).
