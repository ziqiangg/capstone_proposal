# GOV-17

BEACON shall provide a Curator with the means to change, without a code change, each Governed Artefact other than the parameter register, the Methods and the Baselines.

**Rationale.** A Governed Artefact that needs a developer to change stops being changed. Each parameter is changed by its owner (GOV-04). A Method changes only with a release (GOV-18). A Baseline is captured, never edited, and the Curator activates it. The Curator may add subject vocabulary values directly. A source is added (SRC-08), and an Entry part of its entry other than its name, or a Standing, is changed (SRC-36), only by a Curator accepting a version under which BEACON read the source's pages; the Curator edits the rest of the entry directly.
