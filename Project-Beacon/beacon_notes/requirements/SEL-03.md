# SEL-03

BEACON shall include in a Recommendation Set only developments whose Current assessment has a Significance at or above [[MIN_SIGNIFICANCE]].

**Rationale.** What qualifies is the Curator's decision, not a side effect of how much was collected. A Significance of UNKNOWN is not at or above the floor, so the development is not selected; ASM-09 puts it before the Curator.
