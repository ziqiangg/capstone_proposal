# SEL-08

IF a development was in an earlier Recommendation Set and no Materially new information has joined it since, THEN BEACON shall not include it in a later Recommendation Set.

**Rationale.** Repetition is how a recommendation channel gets ignored. The rule applies across all Recommendation Sets, not per Reader.
