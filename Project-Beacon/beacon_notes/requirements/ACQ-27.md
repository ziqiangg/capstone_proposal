# ACQ-27

WHEN a Collection returns an item that is not an Erased item, whose erasure under ACQ-08 a Curator has lifted and whose Article Record keeps no raw page, BEACON shall record the return as a new version of the item's Article Record, containing everything ACQ-02 lists, as a Revision made without comparison, marked as kept after a lift.

**Rationale.** A lift exists so that the item can be collected again (ACQ-23). Its retained text and raw page were removed (ACQ-17, ACQ-18), so there is nothing to compare the return with (ACQ-06); text returning where the record held none is a material change, so the return is a Revision and is processed as one (FBK-06). The mark says it was kept after a lift, without comparison, so that it is never mistaken for a change at the source found by comparison. Once it is recorded, the item's Article Record keeps a raw page again, and its later returns are compared under ACQ-06.
