# GOV-01

BEACON shall allow a user to use a capability only while that user holds the role to which the requirements give that capability.

**Rationale.** Authority follows the role, not the person. The four roles are listed in A-terms A1, where "each capability belongs to exactly one role" is a spec-authoring rule.
