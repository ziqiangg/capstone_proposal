# SRC-38

BEACON shall give each Entry part of a version prepared under SRC-37 a Standing: for a part not re-read, its Standing in the flagged version; for a re-read part, the Standing the re-reading gives it (A-terms, Standing), one SRC-25 names that the source no longer offers being None offered where it was so in the flagged version, else Not established.

**Rationale.** A Collection uses an established part whether or not it was checked, so a Curator accepts a version knowing how far each part was checked (SRC-27). A re-read part is judged as an Onboarding's is, Checked only where pages it was not proposed from bear it out. A part not re-read keeps its Standing. No person reviews the re-reading (SRC-24 binds an Onboarding), so a re-read part SRC-25 names that the source no longer offers is None offered only where the flagged version's was, resting on a Curator's confirmation carried through any versions between (SRC-25); otherwise Not established.
