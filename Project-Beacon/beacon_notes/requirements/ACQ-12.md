# ACQ-12

WHERE BEACON holds a field of an Article Record with no kept value because what it found or supplied for it does not meet ACQ-02, ACQ-10, ACQ-11, ACQ-12, ACQ-13, ACQ-14, ACQ-15 or ACQ-16 or the terms they use, BEACON shall keep every value found or supplied for each of the item's title, Item publisher, Authors and Source publication time, as it stood before, apart from the fields it records.

**Rationale.** Split from ACQ-02. Where what BEACON found does not meet these rows, the field is held with no kept value and what was found is kept apart, so that the record states nothing false and the defect can be examined. An erasure under ACQ-08 removes these values with the item's text and raw page (ACQ-18).
