# ACQ-11

WHERE a Reason for no kept value holds for the title, Item publisher, Authors or Source publication time of an Article Record and BEACON keeps no value the source states for that field, BEACON shall not record that the source states none of it.

**Rationale.** Split from ACQ-02. Where BEACON can keep no value the source states, the record says why rather than that the source states none, so that a gap in BEACON's reading is never read as a gap in the source; a title is then supplied, and the item's source is recorded in place of the Item publisher, each with the reason, so that neither is ever unknown.
