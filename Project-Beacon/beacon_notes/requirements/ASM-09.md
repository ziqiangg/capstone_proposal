# ASM-09

WHEN BEACON records an assessment whose Significance is UNKNOWN, BEACON shall add that development to the next Curator digest.

**Rationale.** An unassessed development cannot be ranked, so it is not selected. The Curator can assess it by correcting the assessment (FBK-02), after which it is selected like any other.
