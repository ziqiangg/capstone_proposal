# ASM-04

WHEN the assessment Method is evaluated, two assessments of the same development from the same input, under the same Method version and the same version of the assessment criteria, shall differ in Significance by no more than [[ASSESSMENT_TOLERANCE]].

**Rationale.** Repeat runs must agree within a stated tolerance. A Method's version includes the model's identity, so a change of model is a trigger (GOV-06).
