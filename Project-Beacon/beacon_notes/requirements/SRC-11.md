# SRC-11

BEACON shall look for candidate sources that are not in the Source Set, without a person starting each search.

**Rationale.** Coverage (A) decays as the field moves to outlets BEACON does not read, so BEACON must not rely only on the sources it was given. How often it looks, and by what means, are design decisions; which candidates it proposes is an open question. A candidate reaches the Source Set only through a Curator (SRC-07, SRC-08).
