# EVD-09

For every Stage that excludes, compresses or summarises, BEACON shall keep each input reachable from the output that replaced it.

**Rationale.** Consolidation must reduce what a Reader reads without reducing what BEACON knows. ACQ-02 and EVD-01 cover retention itself.
