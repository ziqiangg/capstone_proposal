# REL-05

WHEN the scope Method is evaluated against the labelled evaluation set, the proportion of the items that set labels OUT which the Method admits shall be at or below [[MAX_FALSE_ADMIT_RATE]].

**Rationale.** Without a ceiling, a Method satisfies REL-03 by admitting everything. The bound judges the Method over the evaluation set and never gates an item in a Cycle, because an item dropped at admission cannot be recovered.
