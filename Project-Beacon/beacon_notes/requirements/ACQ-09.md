# ACQ-09

WHEN a Re-extraction, other than one that ACQ-30 makes of an item whose text ACQ-07 erased from the version holding its latest raw page, gives a title, Item publisher, Authors or Source publication time that differs from the item's latest version, or extracted text that differs from it where ACQ-07 did not erase the text of the version holding that raw page, BEACON shall record the result, without its extracted text where ACQ-34 applies, as a new version of that item's Article Record, keeping every earlier version.

**Rationale.** A better extraction must not move the evidence under a statement already made: each Evidence locator keeps resolving to the version it was made from (EVD-03). A Re-extraction decides the item's fields again with its text, so a better procedure for the fields reaches the items held as well as new ones. It is not a Revision, since the item has not changed at its source (ACQ-06). A result that changes nothing is confirmed instead (ACQ-33), so each version recorded here is a change. The Re-extractions of one run that record any such version are one trigger (GOV-06), which re-derives Judgements only within the horizon a Curator confirms for it (FBK-09); an item older than that horizon gains the new version and nothing is re-derived for it. Whether a Re-extraction may replace a value a Curator has corrected is not decided here (Q-025).
