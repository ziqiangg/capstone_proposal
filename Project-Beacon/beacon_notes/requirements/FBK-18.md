# FBK-18

BEACON shall record each Revised result with the trigger that produced it, the result it would replace, and the Curator's approval with the Curator and the time.

**Rationale.** Readers are not told that a result was revised, so the record is where the non-Reader roles can see what re-derivation changed, and when it reached Readers.
