# SEL-10

BEACON shall include in a Recommendation Set no development that is withdrawn when that Recommendation Set is selected.

**Rationale.** A withdrawn development may be wrong, and selecting it would put it back before Readers before a Curator has corrected or restored it. The next-ranked qualifying development takes its place, because the bound counts only the developments selected. Once it is corrected or restored, it qualifies again as any development does.
