# OPS-06

BEACON shall Publish the Briefing of each scheduled Cycle whose Recommendation Set holds at least one development, whether or not every enabled source was collected in that Cycle.

**Rationale.** A day with something new reaches Readers even when some sources could not be reached; an unreachable source is logged for the Operator, not a reason to withhold the day's intelligence. Deliveries follow from the Published Briefings (DLV-08).
