# SEL-06

BEACON shall select a Recommendation Set only from assessments made under the version of the assessment criteria in force or, for a development whose re-derivation under that version awaits a Curator's confirmation or approval, from the assessment that re-derivation would replace.

**Rationale.** Significance values are comparable only within one version of the criteria (ASM-02). A re-derived assessment that no Curator has approved is not used, so the prior assessment stands in for it until the approval, even though it was made under the prior version; without that, a change of criteria would empty the Recommendation Set until every re-derivation was approved.
