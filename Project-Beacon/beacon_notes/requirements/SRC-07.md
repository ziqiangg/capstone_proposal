# SRC-07

WHEN BEACON proposes a candidate source, BEACON shall present it to a Curator with the evidence that led to the proposal.

**Rationale.** Whether a candidate belongs in the Source Set is the Curator's decision, and the evidence lets the Curator make it. How BEACON finds candidates is an open question.
