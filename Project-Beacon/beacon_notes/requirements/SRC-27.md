# SRC-27

BEACON shall show a Curator each Onboarding outcome, with each Entry part the Onboarding considered and that part's Standing.

**Rationale.** An established Entry part may be used whether or not it is checked, so the Curator accepts a version knowing how far each part was checked: which parts rest on BEACON's evidence, which on a person's and which on neither (A-terms, Standing). The Curator acts after the Onboarding, on what it found, not before it on a link alone. A refusal is shown too, so that a Curator learns why the source cannot be collected.
