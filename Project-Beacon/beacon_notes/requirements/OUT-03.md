# OUT-03

BEACON shall compose, from each Recommendation Set, one Briefing that contains the Account of each development in that Recommendation Set, in its rank order, and of no other development, together with the description of each active trend.

**Rationale.** A Reader should be able to grasp the period's state from the Briefing alone. The Briefing presents exactly what was selected, so what a Reader reads and what BEACON selected cannot diverge.
