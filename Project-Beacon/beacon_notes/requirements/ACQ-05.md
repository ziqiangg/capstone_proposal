# ACQ-05

WHEN a Collection returns an item that BEACON already holds, BEACON shall record an Encounter of that item, with the source and the collection time.

**Rationale.** How often an item is encountered again is evidence of coverage breadth. If the repeat is suppressed silently, that evidence is lost.
