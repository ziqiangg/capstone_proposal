# GOV-06

BEACON's Trigger Register shall list, each with the Judgements it affects, at least these triggers: a change of any Method version, a change of model identity included; a change of the genre or subject vocabulary; a change of the Scope Criteria or the assessment criteria; the activation of a Baseline; and the Re-extractions that one release, one Curator's acceptance of a corrected Source Set entry or one Operator's command causes (ACQ-28, ACQ-29, ACQ-31), taken together as one trigger, where they record a new version of any Article Record (ACQ-09).

**Rationale.** A stated minimum makes re-derivation predictable. The Curator may register more. GOV-05 versions the register, and FBK-06's split parts say what a trigger causes. A Re-extraction whose result changes nothing records a confirmation, not a version (ACQ-33), so only a run that changes a version is a trigger. A run is one trigger however many versions it changes, so that FBK-08 and FBK-15 add one count to each digest for it and a Curator confirms it once (FBK-10). The Re-extraction made for a returning item (ACQ-30) is part of the record write of that return, a Stage after its Collection (A-terms, Stage), and is no trigger; where the source changed the item, the return is a Revision, which is forward-processed (FBK-06).
