# ASM-02

BEACON shall express every Significance value that one version of the assessment criteria produces on the single scale that version defines.

**Rationale.** Values that are not on one scale cannot be ranked, and ranking is what selection consumes. Selection takes values of one version only, except that a development whose re-derivation under a new version awaits a Curator's confirmation or approval keeps its prior assessment until then.
