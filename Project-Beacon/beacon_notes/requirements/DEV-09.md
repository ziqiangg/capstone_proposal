# DEV-09

BEACON shall extract from each Admitted item the Claims it makes about each development it reports, each with an Evidence locator.

**Rationale.** DEV-03 to DEV-05, and clause (a) of the Materially new information test, act on Claims, but no other row produces them. Claim extraction is a Judgement, so EVD-01 records it.
