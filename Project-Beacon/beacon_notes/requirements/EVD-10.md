# EVD-10

WHEN a Stage fails, BEACON shall record the items, sources and Cycle affected, the Stage, and a failure reason.

**Rationale.** Silent loss looks the same as a quiet week, and it makes coverage permanently unmeasurable. The record is for the non-Reader roles (OPS-07); no Reader output states it. The list of failure kinds is design content.
