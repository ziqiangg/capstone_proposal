# DLV-23

BEACON shall provide an Operator with the means to configure the delivery channel without a code change.

**Rationale.** The delivery channel's configuration is not a parameter, so no parameter owner's means reach it. The Operator already runs the channel (suspension, health, failures), so one role holds it end to end.
