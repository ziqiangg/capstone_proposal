# ACQ-16

WHERE the document an item offers has no text layer or has one that cannot be read, BEACON shall record as the item's extracted text only what it extracts from another form in which the source offers the item, or nothing.

**Rationale.** Split from ACQ-02. A text layer that cannot be read is not passed as the item's text, and no text is made for a document that has none, so that what the record holds as text is what the source offers.
