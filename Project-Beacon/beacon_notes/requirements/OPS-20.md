# OPS-20

IF a scheduled Cycle's Recommendation Set holds no development, THEN BEACON shall record that the Cycle had nothing new, in place of Publishing a Briefing or sending a Delivery for that day.

**Rationale.** An empty Briefing and an empty message cost Readers attention for nothing. A day whose only news is a new Active trend also Publishes nothing, because a Briefing follows its Recommendation Set. The record lets the Operator tell a quiet day from an outage (OPS-23).
