# FBK-23

WHEN a Curator's correction of a Judgement changes a trend or a scope decision that Readers see, BEACON shall show Readers the corrected result marked as corrected, wherever Readers see it.

**Rationale.** A correction that changes what Readers see must show that it changed. A trend or a scope decision belongs to no development's Account, so the correction mark on Accounts (FBK-04) does not reach it; neither is in a Delivery, so no notice is needed.
