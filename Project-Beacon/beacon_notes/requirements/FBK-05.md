# FBK-05

BEACON shall make each correction retrievable as a labelled example holding the input, the original outcome, the corrected outcome, the reason and the provenance class `correction`.

**Rationale.** Corrections made during real work are the best evaluation data available, provided that they stay distinguishable from deliberate labelling.
