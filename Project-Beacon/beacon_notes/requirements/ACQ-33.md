# ACQ-33

WHEN a Re-extraction, other than one that ACQ-30 makes of an item whose text ACQ-07 erased from the version holding its latest raw page, gives a title, Item publisher, Authors and Source publication time the same as the item's latest version, and extracted text the same as it unless ACQ-07 erased the text of the version holding that raw page, BEACON shall record with that version that it was confirmed, with the versions of the procedures and of the Source Set entry that the Re-extraction read.

**Rationale.** A result the same as the version already held would add a version that differs from it in nothing. Recording the confirmation instead says that the version holds under the procedures and entry now in use, beside the versions recorded when it was made (ACQ-36), so a later return is compared with it without being extracted again (ACQ-30), and no trigger is made (GOV-06), so nothing is re-derived for a result that did not change. A procedure's version that changes for a harmless reason then costs only a confirmation.
