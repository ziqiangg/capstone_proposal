# CLS-02

IF no value of the genre vocabulary fits an Admitted item, THEN BEACON shall record a vocabulary gap for that item in place of an item\_type.

**Rationale.** Forcing a bad fit hides the signal that the vocabulary needs extending. The Curator sees each gap in the work list.
