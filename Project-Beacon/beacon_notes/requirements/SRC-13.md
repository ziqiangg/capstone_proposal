# SRC-13

BEACON shall show a Curator, beside each source in the Source Set, the count that SRC-12 keeps for it.

**Rationale.** The Curator owns the Source Set, so the Curator decides whether a failing source stays; a count nobody sees supports no decision. The Operator sees each Failed item, with its source, in the Operator digest.
