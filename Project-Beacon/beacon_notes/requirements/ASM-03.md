# ASM-03

IF no item or Revision has joined a development since its recorded assessment, and no re-derivation covers that development, THEN BEACON shall keep that assessment without assessing the development again.

**Rationale.** Model judgement is not deterministic, so exact repetition cannot be required. What can be required is that nothing is re-run without a cause: re-derivation happens only for a registered reason.
