# SRC-42

BEACON shall re-read, in preparing a version under SRC-37, the Entry parts by which it reads or records what a flag it answers names, or, where one names a whole-Collection event or how often the source's Collections meet an address that is already an address of another item BEACON holds, every Entry part but the source's name, establishing each afresh from the source's pages.

**Rationale.** Re-reading only what a flag names keeps the change small. A whole-Collection event or a rise in addresses already another item's (A-terms, Drift sign) usually means the site was redesigned or re-platformed, so every part is suspect; the name, which nothing reads, stays the Curator's (GOV-17). A re-read part takes its value from the source's pages, and its Standing says how far they bear it out (SRC-38). It is no new source arriving, so it is no Onboarding: SRC-24, SRC-31 and SRC-32 do not bind it, and which pages it reads, and how many, is design.
