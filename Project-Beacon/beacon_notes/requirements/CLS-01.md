# CLS-01

BEACON shall assign each Admitted item that fits the genre vocabulary one or more item\_type values from it.

**Rationale.** Genre is a property of the whole item. It drives triage and eligibility for selection. An item that fits no value is a vocabulary gap (CLS-02), not a forced fit.
