# OUT-05

BEACON shall show a Reader, for each statement in an Account or a Briefing, its statement class and whether it is speculative, and, for each statement in a Delivered entry, whether it is speculative.

**Rationale.** Recording the class (EVD-07, EVD-11) is not the same as showing it. Speculation matters most in a critical-infrastructure channel, and a Delivered entry's share of one message is too short to carry three class labels per statement.
