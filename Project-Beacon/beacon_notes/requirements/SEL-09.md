# SEL-09

IF more developments qualify for a Recommendation Set than [[MAX_RECOMMENDED_DEVELOPMENTS]] allows, THEN BEACON shall keep each qualifying development left out reachable from that Recommendation Set, in rank order.

**Rationale.** The broader picture must stay reachable behind the compression.
