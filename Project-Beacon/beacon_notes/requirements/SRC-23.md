# SRC-23

BEACON shall start an Onboarding only from a link that a Curator gives (SRC-22) or from a candidate source that BEACON's own search has found (SRC-11).

**Rationale.** An Onboarding fetches a source's pages before anyone has decided that BEACON should read it, so what may start one is bounded: a Curator, and BEACON's search for candidate sources, whose candidates otherwise reach a Curator only as proposals (SRC-07). No other role starts one. However it starts, the outcome records who or what started it (A-terms, Onboarding outcome), and the source reaches the Source Set only when a Curator accepts that outcome (SRC-08).
