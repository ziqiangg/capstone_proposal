# EVD-05

IF a statement BEACON composes has no path to an Evidence locator that resolves, THEN BEACON shall neither Publish nor Deliver it.

**Rationale.** A finding nobody can trace is an assertion, and publishing it is a costly failure. A locator into text that has been erased does not count for a new statement. Whether a mapping's evidence supports it is a separate matter (CTX-08, on hold).
