# CTX-02

BEACON shall hold MITRE ATT&CK Enterprise, MITRE ATT&CK ICS, MITRE ATT&CK Mobile and MITRE ATLAS, each in full, as a Baseline.

**Rationale.** Each corpus is versioned independently and changes on its own cadence. Which domain applies to a given development is a design decision, not a row.
