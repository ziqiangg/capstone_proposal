# OUT-04

BEACON shall state, with each Briefing, the value of [[MAX_RECOMMENDED_DEVELOPMENTS]] in force for it and the number of qualifying developments left out of its Recommendation Set.

**Rationale.** A bounded output that is read as complete is misleading. The Briefing is the Recommendation Set written up, so one statement serves both.
