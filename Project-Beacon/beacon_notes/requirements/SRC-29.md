# SRC-29

WHEN a Curator accepts an Onboarding outcome whose Entry part for the source's name is not established, BEACON shall require of that Curator, as part of the acceptance, a name for the source, which the version put into effect holds as the source's name.

**Rationale.** An item that names no publisher has its source recorded in place of one (A-terms, Item publisher), so every entry needs a name for its source. Where the source's pages give none BEACON can establish, or a Curator rejected the one BEACON found (SRC-24), the Curator accepting the outcome gives it, and it becomes the entry's own name. An outcome whose name is established is accepted with that name.
