# C-07 Field decision

## Responsibility
Decides an item's title, Item publisher, Authors and Source publication time from a Page bundle: gathers every value the source states with where it was found, puts each in one form, keeps the Item publisher apart from the Authors and records where the item credits it, keeps one value per field by the order held as data, with every other value the source states beside it, and supplies a title, author or publication time where the source states none that can be kept, with the supplying procedure's version. Each field leaves in exactly one Field state, with its Reason for no kept value where it has none. It is pure: it fetches nothing, reads no store and no clock, and writes nothing, so collection, Re-extraction and onboarding's preview call the same entry points. Its one reason to change is the field procedure's version.
