# C-02 Views

## Responsibility
The backend read side. It builds the Curator and Operator read models by querying the stores directly, distinct from the storage shapes, and is the only source of the frontend's contract; nothing imports it. The Curator view and the Operator view, which the owner intends in React, consume these read models. Not decomposed now: its read-model contract is written when it is entered (owner, 2026-10-08).
