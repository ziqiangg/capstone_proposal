# C-08 Article record

## Responsibility
Holds what BEACON keeps about an item: its versions and their confirmations, its Encounters and Revisions, the raw set each version was extracted from, what a return left unrecorded while its field step or record write is retried, the procedure register, and every erasure and lift. It records each record write's completion time and origin, decides from an Item return or a Re-extraction result whether to write a new version, a confirmation, an Encounter alone or nothing, keeps raw pages readable without the fetcher, answers what is held, serves versions and version reach, and erases and lifts. It fetches nothing and decides no field; collection and the field decision hand it what to write. Its one reason to change is what BEACON keeps about an item, and for how long.
