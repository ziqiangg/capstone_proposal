# C-01 Cycle

## Responsibility
The composition root. It opens and closes each Cycle, records which sources were enabled when it started and which were not collected, and at a Cycle's close hands over to the source watch and then to preparing corrections. It is the only component that wires adapters to the ports the other components own. Not decomposed now: its steps are written when the OPS rows it meets are worked (owner, 2026-10-08).
