# C-03 Digests

## Responsibility
Builds and sends the Curator digest and the Operator digest from read models: each open Drift flag while it is open, each Health entry, preparing results, erasures and Re-extraction runs, breach counts, and the failures the Operator is told of. It owns no fact it reports; the facts belong to the components that produce them. Not decomposed now (owner, 2026-10-08).
