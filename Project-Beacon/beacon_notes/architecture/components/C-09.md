# C-09 Source watch

## Responsibility
Judges, after each Cycle closes, whether a source has changed or is failing. It sits outside what it monitors: it reads the Collection log and health counts collection writes, the record writes, versions and erasures record keeps, and the entry versions, evidence logs and Source state onboarding issues, and changes none of them. From them it raises Drift flags and keeps them open until an event ends them, holding each version's Drift reference for a thing once a Curator has kept that version despite a flag for it (before a keep, the reference is the evidence log's); composes each source's Health entry for each Cycle from the health counts and its Counted versions; counts Failed items per source since its reset point and marks when the limit is reached; counts, per Cycle, the fields held with no kept value for not meeting the rows; notes a source's silence once; and records a Curator's keep of a failing source or of a flagged version. Its one reason to change is how BEACON judges that a source has changed or is failing.
