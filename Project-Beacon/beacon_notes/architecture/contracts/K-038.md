# K-038 Health entry

## Shape
Undesigned: nothing blocks it yet but the design work; what does is asked when it begins. Expected to hold: the A-terms Health entry, per source per Cycle that started with the source enabled: yield; completion and why not, an end under OPS-15 included; listed items not fetched and those not to be tried again; address clashes; whether the listing was read to its end and found only new items; and, over its Counted versions, the text, title, date, disagreement and Reason-for-no-kept-value counts.

## Invariants
One entry per source per Cycle that started with it enabled, none otherwise. Each Counted version is counted in one entry only. Counts, not verdicts.

## Failure
A count whose input is missing is marked missing with its reason, never zero.
