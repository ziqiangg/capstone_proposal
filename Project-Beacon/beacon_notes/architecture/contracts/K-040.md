# K-040 Cycle breach counts

## Shape
Undesigned: nothing blocks it yet but the design work; what does is asked when it begins. Expected to hold: per closed Cycle, per source, part failed and field, the number of fields held with no kept value for not meeting the rows (ACQ-12) in versions whose record writes completed after the previous close and by this one (OPS-29); a run's Re-extractions excluded (OPS-30).

## Invariants
Names, never a value (ACQ-18). Only counts above zero. Each record write counts in one Cycle only.

## Failure
A version whose fields could not be read is listed as uncounted with its reason.
