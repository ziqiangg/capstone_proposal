# K-008 Evidence log

## Shape
Undesigned: nothing blocks it yet but the design work; what does is asked when it begins. Expected to hold: Per-part evidence; each version's Drift reference before it took effect; the D2, D4 and pseudo-part baselines. Not the reference after a keep, which watch owns. Watch consumes it and claims it when decomposed.

## Invariants
Written once, beside the version it belongs to.

## Failure
A baseline missing from the evidence is marked missing, never defaulted.
