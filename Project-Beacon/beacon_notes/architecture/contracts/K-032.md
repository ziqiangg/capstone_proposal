# K-032 Article Record version

## Shape
Undesigned: nothing blocks it yet but the design work; what does is asked when it begins. Expected to hold: one version of one item, with its extracted text, its fields each in a Field state with any Item publisher credit, the kept raw set it names, each procedure version that made it, the entry version and any renderer version (ACQ-36), whether it is a first version, a Revision, a Revision made after a lift, or a Re-extraction's version, and its confirmations, each with the procedure and entry versions read (ACQ-33). Source watch, not yet a C- note, and later Stages will consume it too, so they are named here and not in consumers.

## Invariants
A version is never changed after it is written, except that an erasure removes what it removes. Every earlier version is kept.

## Failure
Undesigned.
