# K-021 Re-extraction run report

## Shape
Undesigned: nothing blocks it yet but the design work; what does is asked when it begins. Expected to hold: From collection to Views (C-02) and Digests (C-03), and to the Trigger Register (GOV-06), not a C- note, so named here; Plan reads it within collection to hold a source's Collection until its owed run is done. One run: its trigger, the new-version count, failures with item, source and reason (ACQ-40), breaches per source, part and field (OPS-30).

## Invariants
Written once, when every Re-extraction in the run has been made or has failed. A zero count is left out.
