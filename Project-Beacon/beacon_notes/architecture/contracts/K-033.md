# K-033 Record write entry

## Shape
Undesigned: nothing blocks it yet but the design work; what does is asked when it begins. Expected to hold: per completed record write, the item, source, entry version, completion time and origin (a Collection with its Cycle; an ACQ-30 Re-extraction within a return; or a run Re-extraction with its kind and run id), and what it wrote: a version with its id, a confirmation, an Encounter alone, or nothing. It gives Counted versions and OPS-29's window. Source watch, not yet a C- note, will consume it too, so it is named here and not in consumers.

## Invariants
One entry per completed record write, written when it completes and never after. A version a run Re-extraction gave is never a Counted version.

## Failure
Undesigned.
