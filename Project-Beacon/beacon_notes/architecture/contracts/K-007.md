# K-007 Source Set entry version

## Shape
Undesigned: nothing blocks it yet but the design work; what does is asked when it begins. Expected to hold: Identified version; Entry parts with Standing; name; fetch modes and their order; render policy; corrects where it is a correction; who accepted and when. Reading, fields, collection, watch and record (by id) consume it too, and claim it when decomposed.

## Invariants
A version is never edited after issue; a changed part is a new version (SRC-36).

## Failure
A version lacking a required part is never issued.
