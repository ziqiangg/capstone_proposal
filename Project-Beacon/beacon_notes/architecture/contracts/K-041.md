# K-041 Silence notice

## Shape
Undesigned: nothing blocks it yet but the design work; what does is asked when it begins. Expected to hold: the source, when it last yielded an item or, if none, when it was enabled, and the close at which SOURCE_SILENCE_PERIOD was found passed (SRC-06).

## Invariants
One notice per silence, for the next Curator digest only. A silence is not a failure.

## Failure
A source whose last yield is unknown gets no notice; the unknown is reported with its reason.
