# K-009 Source state

## Shape
Undesigned: nothing blocks it yet but the design work; what does is asked when it begins. Expected to hold: Per source, each enable and disable with time and Curator (SRC-01, SRC-33). Per entry version, into and out of force, and whether accepted as correcting a flagged version (SRC-39). The Cycle reads which sources are enabled at its start; Views shows it. Collection and watch consume it too, and claim it when decomposed.

## Invariants
Exactly one version of an entry is in force at a time.

## Failure
A state that cannot be read is UNKNOWN to its reader, never enabled.
