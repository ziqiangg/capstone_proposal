# S-007 Issue a version

## What it does
On a Curator's acceptance of an Onboarding outcome that proposes a version, or of a prepared version as correcting the one in force, fixes the parts as one identified version of the Source Set entry, naming the version it corrects where it is a correction, records who accepted and when, and writes the evidence log beside it. Where the source's name is not established, the Curator types it as part of the acceptance.

## Expects
K-006 Onboarding outcome, a proposed version, not a refusal. K-010 Preparing result, a prepared version whose required parts are established, while the version it corrects is in force.

## Produces
K-007 Source Set entry version: the parts with their Standings, the name, fetch modes and their order, the render policy, and corrects where it is a correction. K-008 Evidence log: per-part evidence and the version's Drift reference before it took effect.

## Done when
No version comes into being except from an accepted outcome or an accepted prepared version (SRC-08, SRC-36), and each carries a name.

## Failure
A refusal, a prepared version lacking a required part, or one whose corrected version is no longer in force cannot be accepted; it is shown and nothing is issued. An acceptance without a name where one is needed is refused, not given a default name.
