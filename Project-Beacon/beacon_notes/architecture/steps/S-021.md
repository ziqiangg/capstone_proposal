# S-021 Put in one form

## What it does
Puts each candidate in one form: a title's whitespace and markup, an author credit split into names, a time read into an instant or into the precision the source states it at (a month, a quarter, a year). A value that cannot be read without guessing is held only as found, with that reason, and is never put in a form that would let it be kept (ACQ-10). The value as found is carried beside its form (ACQ-12).

## Expects
K-027 Candidates.

## Produces
K-028 Normalised values: per candidate, its value as found, its place, and either its one form with its precision or that it cannot be read without guessing.

## Done when
Every candidate has a form or the reason it has none, and every value as found survives unchanged.

## Failure
A value that cannot be read is marked so, with the reason; no form is guessed and no precision is invented. A date the source gives only as when the item last changed is marked as not a publication time.
