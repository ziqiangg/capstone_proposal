# S-024 Supply

## What it does
Supplies a title wherever the title is None stated or has no kept value, and an author or a publication time where the procedure supplies one, each as a Supplied value, never as stated by the source (ACQ-13). Each names the supplying procedure's version and, where a model supplied it, the model's identity, the wording of its prompt and its settings; the version is the digest of the procedure's description generated at build (D-004), which leaves out the Source Set entry (ACQ-14). For the Item publisher it puts the item's source as its Item publisher where it is None stated, and in place of it where it has no kept value, with the reason (ACQ-11); that is not a Supplied value.

## Expects
K-030 Kept values: which fields are None stated or have no kept value. K-017 Page bundle: what a supplying procedure reads. K-007 Source Set entry version: the source, for the Item publisher.

## Produces
K-031 Supplied values: per field supplied, the value, the procedure's version and, for a model, its identity, prompt wording and settings; for the Item publisher, the source as or in place of it, with the reason.

## Done when
No title and no Item publisher is left without a value, and every Supplied value names its procedure's version.

## Failure
A procedure that cannot supply a title gives that reason and the title stays with no kept value; it is reported, never filled with a default title. No author or time is supplied by default: where none is supplied, the Authors or the Source publication time is unknown, with its reason.
