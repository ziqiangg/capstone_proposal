# S-034 Compose the Health entry

## What it does
When a Cycle closes, composes the Health entry of each source enabled when that Cycle started, an end under OPS-15 included: the health counts collection logged for its Collection, and the counts over its Counted versions, the versions recorded from a Collection's returns whose record write completed by this close and that no earlier Health entry counted, a version a Re-extraction gave being none. A version whose record write completed in a Cycle that started with the source disabled is counted in the source's next entry. This is the health half of the digest's health report; Digests own the digest half.

## Expects
K-043 Cycle record: start and close, the sources enabled at start, and those not collected (OPS-15). K-007 Source Set entry version: whether the source is collected from a feed or a listing page. K-009 Source state: when the source was enabled again. K-020 Collection log and health counts: yield, completion and reason, listed items not fetched and those not to be tried again, address clashes, the listing read to its end. K-033 Record write entry: completion time and origin, which select the Counted versions. K-032 Article Record version: what each Counted version holds.

## Produces
K-038 Health entry: one per source per Cycle that started with it enabled, and none otherwise.

## Done when
Every source enabled at a closed Cycle's start has one Health entry for it, and every Counted version is counted in exactly one entry.

## Failure
A count whose input is missing is marked missing with its reason, never zero; the entry is still written with the counts that could be formed.
