# S-003 Draw a sample

## What it does
Has collection fetch up to ONBOARDING_SAMPLE_SIZE items spread across the periods the source lists items from, raw and rendered, or every item where the source lists fewer, and splits them by alternation within periods into derive pages and check pages.

## Expects
K-002 Acceptance, with leave to go on. K-013 Fetched item, one per sampled item.

## Produces
K-003 Sample: the derive pages and the check pages, the periods drawn from, the count sampled, and every page read, so test draws can leave them out.

## Done when
The sample is the full size, or the whole listing where it is smaller, spread across periods, and no page is both a derive and a check page.

## Failure
A refused Acceptance draws nothing. A sampled item that cannot be fetched is replaced from its period where one is left, else the sample is smaller and says so. BEACON's own failure ends the run (SRC-34).
