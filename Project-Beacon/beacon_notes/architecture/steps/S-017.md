# S-017 Classify

## What it does
Classifies each Fetched item against the held view: not held; held and unchanged (an Encounter); held and changed (an Encounter and a Revision); held and erased so that it is not compared. Where the held text was not made by the procedures now running or under the entry version this return was read under, or its text was erased under ACQ-07, the held item's kept page is re-extracted first and the comparison is made with that (ACQ-30); no Erased item is re-extracted (ACQ-35). It hands the return to page reading, to the field decision through the Page bundle and to the article record through the Item return.

## Expects
K-025 Item reference: the key, aliases and what is held of the item. K-013 Fetched item. K-007 Source Set entry version the return was collected under. K-015 Held view: held items, erasure kind, the held text's procedure and configuration versions. K-012 Extraction of the return. K-014 Field set of the return. K-019 Re-extraction result of the held page, for the comparison under ACQ-30.

## Produces
K-017 Page bundle: the return's pieces as the field decision reads them. K-018 Item return: its kind, raw set, Encounter, Collection and Cycle, and for a returning item its ACQ-30 Re-extraction result.

## Done when
Every Fetched item gives one Item return of one kind, and every comparison is made between texts from the same procedures and entry version.

## Failure
A re-extraction for the comparison that fails gives an Encounter marked not compared, with the reason; it is never read as unchanged. A Held view that cannot be read gives no Item return for the item, with that reason.
