# S-029 Answer what is held

## What it does
Answers, for collection and onboarding, which items BEACON holds and in what state: each held item with its alias owner and listed address, whether it is an Erased item or had only its text erased, whether its record keeps a raw page, and the procedure and entry versions its latest text was made under (ACQ-36), so a return can be classified as not held, unchanged, changed or erased (ACQ-04, ACQ-06, ACQ-22, ACQ-25, ACQ-27).

## Expects
K-032 Article Record version: the latest version of each item and its versions. K-022 Kept raw set: whether one is kept and when it was collected. K-035 Erasure entry and log: each erasure and lift in force.

## Produces
K-015 Held view.

## Done when
Every item held or erased is answered with its state as of the last completed record write and erasure.

## Failure
A view that cannot be built is reported as unreadable, never as nothing held; an item whose erasure state cannot be read is not answered as not Erased.
