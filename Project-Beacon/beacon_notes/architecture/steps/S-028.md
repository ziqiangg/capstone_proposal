# S-028 Hold pending material

## What it does
Holds what a Collection returned for an item and BEACON has not yet recorded, because its field step or its record write failed or has not completed (A-terms, Stage), so the step can be tried again. A later return of the same item replaces what is held of the earlier one (ACQ-38); the item stays the same item for the counts other components keep.

## Expects
K-018 Item return: a return whose record write has not completed.

## Produces
K-036 Pending return: per item, at most one return held unrecorded, with its Encounter details, its raw set and whatever text it carries.

## Done when
Every return whose record write has not completed is held, at most one per item, until its record write completes or an erasure completes it.

## Failure
A pending return that cannot be stored is reported as a failed record write of that return; it is never dropped silently.
