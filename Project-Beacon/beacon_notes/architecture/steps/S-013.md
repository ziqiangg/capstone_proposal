# S-013 Walk the listing

## What it does
Reads the configured listing of the source, as its entry version locates it, to its end or to the first page of items already held, never an archive. The listing part is applied through page reading. For a dated listing it takes the entries after the newest held item, and on a first Collection the newest only. Each entry is passed on with the markup it came from, whatever date it gives (ACQ-01).

## Expects
K-023 Collection plan. K-007 Source Set entry version: the listing's address and the part that locates it. K-011 Part result: whether the listing part found its entries on each listing page. K-015 Held view: the newest held item, and whether a listing page holds only held items.

## Produces
K-024 Listing entry: one per entry read, with the listing it came from; and whether the listing was read to its end (SRC-04).

## Done when
Every entry of every listing page read is passed on, none dropped for its date, and whether the listing was read to its end is known.

## Failure
A listing that cannot be read, or whose page shows nothing the entry holds for locating it, is "listing failed" for the Collection, not an empty listing (SRC-04). A Held view that cannot be read stops the walk with that reason; it is never read as nothing held.
