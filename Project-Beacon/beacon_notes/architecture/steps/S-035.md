# S-035 Count source failures

## What it does
Keeps, per source, the count of its items that have become Failed items since its reset point, the latest of: added to the Source Set, last enabled by a Curator, last kept by a Curator (SRC-15). Each item is counted once, however many Cycles it fails in. When the count reaches SOURCE_FAILURE_LIMIT it marks the limit reached, with the Failed items and their reasons, for the Curator digest (SRC-14) and for the notice to every Operator (OPS-21).

## Expects
K-020 Collection log and health counts: which items became Failed items, with their reasons. K-007 Source Set entry version: when the source was added. K-009 Source state: when a Curator last enabled it, and its removal. K-042 Keep: the latest keep of a failing source.

## Produces
K-039 Source failure state: the count since the reset point, the reset point, whether and when the limit was reached, the Failed items and their reasons, and the keeps.

## Done when
Each source's count equals the number of distinct items that became Failed items since its reset point, and the limit is marked once per reset.

## Failure
A log line that cannot be read leaves the count marked incomplete with its reason; it is never counted as zero failures.
