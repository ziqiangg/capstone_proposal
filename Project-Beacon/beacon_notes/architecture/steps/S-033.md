# S-033 Watch for drift

## What it does
When a Cycle closes, forms each enabled source's Drift check: the version in force at the close and the things it covers, leaving out a thing with an open flag, a thing judged by one page or one Collection after a keep for it, and a whole-Collection event of a Collection that began before the source was last enabled again. For each covered thing it fills the Drift window (Collections, listed items tried, or items recorded, at most DRIFT_WINDOW of the latest under that version, leaving out Erased items and handling lifts and the restart points the A-terms name) and judges it against the Drift reference: as a rate at DRIFT_ALPHA (SRC-16, the drift statistics as a pure module), by one page contradicting it (SRC-20), or by one Collection meeting a whole-Collection event (SRC-21). It raises a Drift flag for each departure, and keeps each flag open until a disable, an accepted correction, a keep, the version leaving force or the source's removal ends it, so that each digest can repeat it while open (SRC-17). It holds each version's Drift reference for a thing after a keep (SRC-18); before any keep the reference is the evidence log's.

## Expects
K-043 Cycle record: the close, and the sources enabled at the Cycle's start. K-007 Source Set entry version: what the version holds about the source's pages. K-008 Evidence log: each version's Drift reference before it took effect, and the baselines. K-009 Source state: enables, disables, removal, versions into and out of force, and acceptance as correcting a flagged version. K-020 Collection log and health counts: whole-Collection events and listed items tried with their latest try's outcome. K-032 Article Record version and K-033 Record write entry: the items recorded, by the latest return whose record write completed. K-035 Erasure entry and log: Erased items and lifts. K-042 Keep: keeps of a version despite a flag.

## Produces
K-016 Drift flag: one per departure per thing, on the check's version, with what BEACON saw, its raise time and its open state.

## Done when
After a close, every covered thing of every Drift check has been judged once, every departure has one flag, and every flag whose ending event has occurred is closed with that event named.

## Failure
A thing whose reference or window cannot be formed is not judged and is recorded as not judged with its reason; it never raises or clears a flag by default. A missing Cycle record stops the step for that close.
