# S-012 Plan

## What it does
At a Cycle's start, takes exactly the sources enabled then (SRC-10), each with the one Source Set entry version in force, and starts one Collection per source in parallel, each with its deadline (OPS-15). A source whose entry names no established ways of fetching and their order is not collected (SRC-30). A source with a Re-extraction run still owed under ACQ-28 or ACQ-29 is collected only once that run has been made or has failed. The Cycle component (C-01) will later own the Cycle's open and close; this step stays here until then.

## Expects
K-007 Source Set entry version: the version in force, its ways of fetching and their order. K-009 Source state: which sources are enabled at the Cycle's start and which entry version is in force. K-021 Re-extraction run report: that a run owed before the source's next Collection has been made or has failed.

## Produces
K-023 Collection plan: one per source collected, with its entry version, Cycle, start and deadline, and whether it is a first Collection.

## Done when
Every source enabled at the Cycle's start has one Collection plan or a recorded reason it is not collected, and no other source has one.

## Failure
Source state that cannot be read starts no Collection and records why; it never defaults to the previous Cycle's sources. No entry version in force, or no established order of fetching, starts no Collection for that source, with the reason.
