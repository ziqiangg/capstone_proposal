# S-010 Apply an Entry part

## What it does
Applies one Entry part, as a version of a source's Source Set entry holds it, to one page, trying each of the part's ways in order, and says whether the part found what it is for, matched nothing or could not be evaluated, with the value and where on the page it lies. Onboarding applies proposed parts through it; collection applies an entry version's parts through it; Extract text applies the configured body part through it. It reads only the page it is given and fetches nothing that page would load (ACQ-03).

## Expects
K-007 Source Set entry version: the Entry part to apply and its ways, in order. K-013 Fetched item, or the kept pieces of one in the same form: the labelled page the part is applied to, and what was not obtained.

## Produces
K-011 Part result: per part and page, exactly one outcome of found, matched nothing or could not be evaluated, with the value and its place where found.

## Done when
Every part applied to a page gives exactly one outcome, the same for the same part and page wherever it is called.

## Failure
A page piece the part needs that was not obtained, or a way that cannot be run on the page, gives could not be evaluated, never matched nothing. A missing part or page is refused to the caller; no outcome is made for it.
