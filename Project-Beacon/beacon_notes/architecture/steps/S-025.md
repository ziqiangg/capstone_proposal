# S-025 Assemble the field set

## What it does
Assembles one Field set for the item: each field's Field state with its kept value, places, other values, Reason for no kept value and Supplied value; the credit to the Item publisher or the source; and every value found as it stood where a field has no kept value (ACQ-12). It names the item, whether the bundle came from a fetch or a Re-extraction, the field procedure's version and the Source Set entry version it was read under.

## Expects
K-029 Publisher credit. K-030 Kept values. K-031 Supplied values. K-017 Page bundle: the item, and whether it is a fetch or a Re-extraction. K-007 Source Set entry version: its identity.

## Produces
K-014 Field set: the four fields, each in exactly one Field state, with the credits and the versions, for collection, the article record and onboarding's preview.

## Done when
Every Page bundle given yields one Field set in which each field has one Field state, no title or Item publisher is unknown, and every Supplied value names its version.

## Failure
A field that reaches it in no Field state, or in two, is set to no kept value with the failing part named (ACQ-12); it is never filled with a default.
