# S-008 Prepare a correction

## What it does
At a Cycle's close, for each source whose version in force has Drift flags the close raised or that stay open, re-reads the parts SRC-42 names on pages it reads under the whole version, holding the rest, gives each part its Standing (SRC-38), and prepares one correcting version unless nothing would change. It retries an attempt BEACON's own failure ended up to a bound, and records each attempt.

## Expects
K-016 Drift flag, open, on the version in force. K-007 Source Set entry version and K-009 Source state, for the version in force. K-013 Fetched item for fresh pages. K-011 Part result, K-012 Extraction and K-014 Field set as Check parts uses them, with their procedure versions (D-004).

## Produces
K-010 Preparing result: one row per attempt, with the close that started it, the flags served, the attempt against its bound, and a prepared version, found none, or ended by failure with its reason and whether the bound was reached.

## Done when
Each close with open flags on a version in force gives one Preparing result per attempt, and a failure past the bound is reported once per flag (SRC-41).

## Failure
A flag that cannot be read prepares nothing for it and is not taken as closed. A re-read part that cannot be evaluated is Not established, unless SRC-38 keeps None offered. BEACON's own failure retries up to the bound, then waits for the next close.
