# S-005 Check parts

## What it does
Applies each proposed part to the check pages through reading, takes the extraction and the field decision on them for the preview and the baselines, and gives each part its Standing so far: Checked where pages it was not proposed from bear it out, Not checked where a value is established but not so borne out, None offered only where SRC-25 allows it without a Curator, Not established otherwise. It writes the evidence and the D2, D3 and D4 baselines.

## Expects
K-003 Sample, its check pages. K-004 Proposed part. K-011 Part result per part per check page. K-012 Extraction and K-014 Field set per check page, each with the procedure version that made it (D-004).

## Produces
K-005 Checked part: per part, its Standing, the evidence per check page, and the baselines with the procedure versions they were taken under.

## Done when
Every proposed part has exactly one Standing and its evidence, and no part SRC-25 names is None offered here.

## Failure
A part whose results could not be evaluated on a page is not Checked on that page, and the evidence says could not be evaluated. A missing Extraction or Field set leaves its baseline absent and marked so. BEACON's own failure ends the run (SRC-34).
