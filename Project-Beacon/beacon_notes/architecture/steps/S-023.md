# S-023 Group and keep one

## What it does
For each field, groups the values that agree and keeps one by the order held as data in the field procedure, with every other value the source states beside it where they disagree; for the Authors, every Author the source states that can be read without guessing (ACQ-10). It gives each field its Field state: Kept, None stated, or No kept value with its Reason for no kept value (ACQ-11). A value that does not meet the rows is not kept: the field has no kept value with the part it fails named, and every value found is carried as it stood (ACQ-12).

## Expects
K-028 Normalised values for the title and the Source publication time. K-029 Publisher credit for the Item publisher and the Authors.

## Produces
K-030 Kept values: per field, its Field state; the kept value as found and in one form, with its place; the other values with theirs; the Reason for no kept value where there is one; every value found, as it stood.

## Done when
Each of the four fields has exactly one Field state, and none is None stated where a place went unread or a part was not obtained.

## Failure
Where values disagree and the order does not settle it, the field has no kept value with that reason; one is never picked by default. Missing input gives No kept value with the reason, never None stated.
