# S-019 Re-extract

## What it does
Re-extracts an item from the latest raw page its record keeps, read through the article record and never from the source (ACQ-03): runs page reading over the kept pieces and gives the field decision a Page bundle built from them. It runs on a release (ACQ-28), a Curator's acceptance of a correcting entry version (ACQ-29) and the Operator's command (ACQ-31), and for a returning item when Classify asks (ACQ-30). It reads the entry version ACQ-32 names, never reaches an Erased item (ACQ-35), and gives each item a Re-extraction result for the article record to write as a new version (ACQ-09) or a confirmation (ACQ-33). For a run it rolls the results and failures into one run report (ACQ-37, ACQ-40, OPS-30).

## Expects
K-022 Kept raw set: the labelled raw pieces of one fetch. K-007 Source Set entry version, the one ACQ-32 names. K-009 Source state: which version a Curator accepted as correcting which. K-015 Held view: which items are Erased, under which version and when each latest raw page was collected, and with which procedure versions their text was made. K-012 Extraction and K-014 Field set made from the kept pieces.

## Produces
K-019 Re-extraction result: one per item re-extracted, with its run or the return that caused it. K-021 Re-extraction run report: one per run, once every Re-extraction in it has been made or has failed.

## Done when
Every item a trigger reaches has a Re-extraction result or a reported failure, and each run has one report once all are made or failed.

## Failure
A kept raw set that cannot be read gives no result, so nothing is recorded and the item stays on its latest version; the failure, with item, source and reason, goes to the run report (ACQ-40). A Held view that cannot be read starts no run; no item is assumed not Erased.
