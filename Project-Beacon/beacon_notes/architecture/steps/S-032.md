# S-032 Hold the register

## What it does
Holds the procedure register: each procedure version's description, copied once from the release's procedures file and checked against the version's digest (D-004), with the model's identity, prompt wording and settings where a model supplies values, and no Source Set entry (ACQ-14). It keeps a description for as long as any version names it (ACQ-14, ACQ-36).

## Expects
K-032 Article Record version: which procedure versions any version still names.

## Produces
K-037 Procedure description: one per procedure version, unchanged once held.

## Done when
Every procedure version a version names has exactly one description whose digest matches it.

## Failure
A description whose digest does not match its version is refused (D-004), and any write naming that version waits; no description is written by hand or defaulted.
