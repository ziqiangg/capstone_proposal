# S-030 Serve a version and version reach

## What it does
Serves the record's read side: any version of an item by its id, every earlier version kept (ACQ-06, ACQ-09), with its confirmations, its raw set and the description of each procedure version it names (ACQ-14, ACQ-36), with whatever an erasure removed left out. For one source and entry version, at the time asked, it answers version reach: the items not Erased whose latest raw page was collected under that version, and the items with no raw page whose latest version was made under it.

## Expects
K-032 Article Record version. K-022 Kept raw set: the entry version each latest raw page was collected under. K-035 Erasure entry and log: what to leave out and which items are Erased. K-037 Procedure description. K-007 Source Set entry version: the version a reach is asked for.

## Produces
K-034 Version reach. It serves K-032 as written by S-027; it adds nothing to a version.

## Done when
Every version a reader names is served as recorded, less what an erasure removed, and a reach asked at a time counts each item at most once.

## Failure
A version that cannot be read is reported as unreadable, never served as empty. A reach whose inputs cannot be read is refused, not answered as zero.
