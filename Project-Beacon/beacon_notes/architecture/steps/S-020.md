# S-020 Gather candidates

## What it does
Gathers every value the source states for each of the item's title, Item publisher, Authors and Source publication time from the Page bundle: the page's metadata, the Entry parts that locate a field, applied through Apply an Entry part, and the listing entry's date for an item the source publishes itself. Each value is taken as found, with the place it was found (ACQ-10). A place that could not be read, and a part not obtained, are recorded by name, never skipped (ACQ-11). It supplies nothing.

## Expects
K-017 Page bundle: the page, the rendered copy and the listing entry, or that each was not obtained. K-007 Source Set entry version: the Entry parts that locate field values. K-011 Part result for each of those parts: found, matched nothing or could not be evaluated, with value and place.

## Produces
K-027 Candidates: per field, every value found as found, each with its place; every place that could not be read and every part not obtained, named.

## Done when
Every place the field procedure reads for a field is either a candidate with its place or named as unread or not obtained.

## Failure
A missing piece of the bundle, or a part that could not be evaluated, is named as such in the candidates; it is never read as the source stating no value.
