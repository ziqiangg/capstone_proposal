# S-036 Count Cycle breaches

## What it does
When a Cycle closes, counts the fields held with no kept value for not meeting the rows (ACQ-12) in versions recorded by record writes completed by this close and after the previous Cycle's close, per source, part failed and field, naming each and never a value, and keeping only counts above zero. A returning item's Re-extraction within a return counts; a run's Re-extractions are reported by run (OPS-30) and do not.

## Expects
K-043 Cycle record: this close and the previous one. K-033 Record write entry: completion time and origin. K-032 Article Record version: the fields held with no kept value for that reason, and the part that failed.

## Produces
K-040 Cycle breach counts: per Cycle, per source, part failed and field, each count above zero.

## Done when
Each record write completed between two closes is counted in exactly one Cycle's breach counts.

## Failure
A version whose fields cannot be read is reported as uncounted with its reason, never left out silently.
