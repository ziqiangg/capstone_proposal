# S-027 Write a version or a confirmation

## What it does
Makes the record write. From an Item return: a first version for an item not held (ACQ-02); an Encounter with source and collection time for an item held (ACQ-05), and nothing more where its text is unchanged (ACQ-04); a Revision keeping the prior version where it changed (ACQ-06); a Revision made without comparison, marked as kept after a lift, where a lifted item keeps no raw page (ACQ-27); and for an Erased item its Encounter alone, marked as not compared, where it is held, and nothing where it is not (ACQ-22, ACQ-25). From a Re-extraction result: a new version where a field or the text differs, without text where ACQ-34 applies (ACQ-09), or a confirmation with the procedure and entry versions read (ACQ-33). Each version names its kept raw set, each procedure version that made it, the entry version and the renderer version (ACQ-36), and a Supplied value's procedure by its version in the register (ACQ-14). Where an erasure reaches an item with a pending return, it completes that return's record write with its Encounter alone, or with nothing where the item is not held (ACQ-41, ACQ-42). Each record write ends with one Record write entry giving its completion time and its origin, which keeps a returning item's own Re-extraction apart from a run's (D-002).

## Expects
K-018 Item return: its kind, raw set, Field set, Encounter, Collection and Cycle, and any ACQ-30 Re-extraction result. K-019 Re-extraction result: the run or return that caused it, the Extraction and Field set, and the versions read. K-014 Field set: each field's value and Field state, read as written into the version. K-007 Source Set entry version: the id recorded with the version. K-022 Kept raw set: the id the version names. K-035 Erasure entry and log: whether the item is Erased, or was lifted. K-036 Pending return: a return held unrecorded, to retry or to complete under an erasure. K-037 Procedure description: every procedure version named is in the register.

## Produces
K-032 Article Record version: each version as written, with its confirmations. K-033 Record write entry: one per completed record write, saying what it wrote.

## Done when
Every Item return and Re-extraction result handed to the record ends in exactly one completed record write with its Record write entry, and no write leaves a version without its raw set, entry version or procedure versions.

## Failure
A write that cannot complete writes nothing partial: the return is held as pending (S-028) and no Record write entry is made. A procedure version the register does not hold, a missing entry version or an unreadable erasure state refuses the write; none is defaulted. A comparison that fails is not recorded as an unchanged return (ACQ-25).
