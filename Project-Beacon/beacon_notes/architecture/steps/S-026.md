# S-026 Keep the raw set

## What it does
Keeps the raw set an Item return carries, the item's Raw page as the Collection returned it: its pages, each page as rendered where it was rendered with the renderer's version (ACQ-36, D-004), and its listing entry. It keeps it for a new item (ACQ-02), a Revision (ACQ-06) and the first return after a lift (ACQ-27), so a Re-extraction and a reviewer can read it without the fetcher, until an erasure removes it. It keeps nothing of the return of an Erased item (ACQ-22).

## Expects
K-018 Item return: its kind and its raw set. K-035 Erasure entry and log: whether the item is an Erased item, held or not.

## Produces
K-022 Kept raw set: the labelled raw pieces of one fetch, byte for byte as returned, under an id a version can name.

## Done when
Every version the record writes names a kept raw set that can be read back unaltered, and no raw set of an Erased item's return is kept.

## Failure
A raw set that cannot be stored leaves the return unrecorded and held as pending (S-028); no version is written without its raw set. An erasure state that cannot be read keeps nothing; the item is never assumed not Erased.
