# S-009 Set a source's state

## What it does
Records each enabling and disabling of a source with its time and Curator, enabling a source when its first version is issued (SRC-33), and records each version's coming into force and going out of it, and whether it came in as correcting a flagged version.

## Expects
K-007 Source Set entry version, each newly issued one; and a Curator's enable or disable, which changes no version.

## Produces
K-009 Source state: per source, its enable and disable history; per version, into and out of force and whether accepted as a correction.

## Done when
At any time exactly one version of an entry is in force, and each source is either enabled or disabled, with who set it and when.

## Failure
An enable or disable for a source not in the Source Set is refused. Two versions issued for one source at once are not both put in force: the later acceptance is refused and shown.
