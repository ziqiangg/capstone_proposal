# S-037 Note silence

## What it does
When a Cycle closes, finds each enabled source for which SOURCE_SILENCE_PERIOD has passed since it last yielded an item, or since it was enabled if it has yielded none, and notes that silence once, for the next Curator digest. A silence ends when the source yields again; a new silence is noted anew. Silence is not a failure and adds nothing to the source's count.

## Expects
K-043 Cycle record: the close time. K-020 Collection log and health counts: when the source last yielded an item. K-007 Source Set entry version: the source. K-009 Source state: whether it is enabled, and since when.

## Produces
K-041 Silence notice: the source, when it last yielded or was enabled, and the close at which the silence was noted.

## Done when
Each silence of an enabled source produces exactly one notice.

## Failure
A source whose last yield cannot be read is reported as unknown with its reason, never as silent or as yielding.
