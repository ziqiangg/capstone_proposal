# Q-004 Internal uses of OSCAL and STIX

## What is unknown

Which internal uses, if any, should OSCAL or STIX serve in BEACON: importing a corpus, detecting a corpus's new version, or a common internal shape for controls and techniques? Export to Readers' own tools is a separate question ([[Q-015]]).

## Why this priority

P2: no framework component is being decomposed yet, and reading each corpus in its publisher's own format costs nothing until then. It becomes P1 when the framework component is entered, since a format choice is expensive to reverse.

## Answered when

For each of the three uses, a written comparison over the initial Baselines ([[D-003]]) states what OSCAL or STIX would save or cost against the publisher's native format, and the owner accepts one or more uses, or none.

## If it stays unknown

Each corpus is captured and read in its publisher's own format ([[CTX-09]], [[CTX-12]]); BEACON holds no common internal shape.
