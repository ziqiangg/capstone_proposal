# Q-010 The labelled evaluation set

## What is unknown

Which items, labelled by whom, and how many, should make up the labelled evaluation set against which the scope Method is evaluated ([[REL-04]], [[REL-05]], [[REL-06]])?

## Why this priority

P1: the scope Method cannot be judged against [[MAX_MISSED_RATE]], [[MAX_FALSE_ADMIT_RATE]] and [[MAX_ABSTENTION_RATE]] without it, and that work is about to start. It can proceed on a provisional set, so it is not P0; it is not P2, because a set too small or too narrow passes a weak Method.

## Answered when

The set holds items from every initial source, each labelled `IN` or `OUT` by two labellers with every disagreement resolved, and is large enough that each of the three rates is estimated within 0.03 at 95 per cent confidence.

## If it stays unknown

A provisional set of 300 items from the trial sources, labelled by a Curator, stands in, and each evaluation result is reported with its sample size.

## Evidence so far

Collecting [[X-002]]'s hand labels showed how a label sheet can be corrupted without the labeller seeing it: a spreadsheet re-encoded the file (Windows-1252), rewrote ISO dates as day/month/year, and filled a column of dates as a running series. Every error was caught only by checking the file after it was returned. A labelled set needs a form that keeps text and dates exactly and validates entries as they are made.
