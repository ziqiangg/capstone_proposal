# Q-012 Trend identity across windows

## What is unknown

How should BEACON decide that a trend identified over one [[TREND_WINDOW]] is the same trend as one identified over an earlier window, so that [[TRD-02]] can characterise it?

## Why this priority

P1: it shapes the trend work, which can proceed under the fallback, so it is not P0. It is not P2, because the fallback makes the characterisation mostly `UNKNOWN`, which Readers see. An experiment is likely; candidate criteria are the overlap of constituent developments, shared subject tags or mapped framework items, and a Judgement by the trend Method.

## Answered when

A stated criterion, measured on a labelled set of window pairs, agrees with the labellers' same-or-different decisions on at least 90 per cent of the pairs.

## If it stays unknown

A trend that BEACON cannot match to an earlier window's trend is characterised `UNKNOWN` ([[TRD-02]]).
