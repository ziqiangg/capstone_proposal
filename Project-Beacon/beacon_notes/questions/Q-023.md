# Q-023 How later Stages use where a metadata value came from

## What is unknown

An Article Record holds each title, author set and publication time in a Field state ([[ACQ-10]]): where each value the source states was found, every other value where they disagree, a Supplied value with the procedure that supplied it ([[ACQ-13]]), or no kept value with its reason. Which later Stages read that, and does a value found in one place, one the source contradicts, a Supplied value or a field with no kept value weigh less there than a value found in two or more places that agree: in placing an item in time, in a development's account of its sources, or in the confidence a Judgement states ([[EVD-02]])? Where is that decided: in each Stage's Method, or once for all? [[Q-011]] asks for the scale on which a Method states its confidence and the words a Reader sees; it does not ask whether where an input field's value came from enters that confidence, so it does not cover this.

## Why this priority

P2: where each value was found, or what supplied it, is kept with every value, so nothing is lost while this waits. It is not P1, because no work about to start reads it; it becomes P1 when the first Stage that orders or weighs items by their metadata is designed.

## Answered when

The owner rules whether later Stages read where a value was found or that it was supplied, whether that is settled once for all or in each Stage's Method, and what is done with each set of places, with Supplied values, with values the source contradicts and with fields with no kept value, citing the measured rate at which the values of each are right ([[Q-022]] asks for that rate for dates, for each set of places, for Supplied values by the procedure that supplied them and for fields held with no value, not for values the source contradicts); and the design of each Stage that reads an item's title, authors or publication time names which of these it handles.

## If it stays unknown

Every value is kept in the Article Record with where it was found or what supplied it. Later Stages treat every value alike, wherever it came from, and no Reader sees where it came from.

## Evidence so far

On [[X-006]]'s 58 kept test pages, in X-006's own status words: titles agreed on 55 and single on 3; authors agreed on 16, single on 14, empty on 27 and disputed on 1; publication times agreed on 2, single on 49 and fallback on 7. Most publication times therefore rest on one source, while most titles are agreed. On those pages the statuses did not separate right from wrong: every title and date there was right, and the one disputed author set kept its declared value. Agreement is not truth either: on check S123 two sources agree on a date its label rejects. No held-out rate per set of places exists.
