# Q-025 Correcting an Article Record's metadata, and showing Readers what BEACON supplied

## What is unknown

Who may correct a title, an author, a publisher or a publication time that an Article Record holds ([[ACQ-02]]), how is the correction recorded, and do Readers see that a value was supplied by BEACON and not given by the source? A Curator has the means to correct any Judgement ([[FBK-01]]), and [[FBK-23]] shows Readers a corrected trend or scope decision as corrected. Recording an Article Record's fields is not on the closed Judgement list ([[A-terms]] A2), and [[CP-001]] proposes to say so in terms, by the owner's ruling of 2026-10-01. So neither of those rows reaches a metadata value, whether BEACON copied it from the source or supplied it where the source gave none. How a correction is recorded includes whether a later derivation of the same page may overwrite it. The owner posed this as one question when ruling that a supplied value is not a Judgement.

## Why this priority

P2: under the fallback a wrong value stays as recorded and is not hidden, and [[X-006]]'s test supplied no title and no author. It is not P1, because no work about to start turns on it; it rises when a Reader-facing output that shows these fields is designed, or when a run measures a model supplying a title ([[Q-024]]).

## Answered when

The owner rules who may correct each of these fields, for a copied value and for a supplied one; what a correction records, and whether a later derivation of the same page may overwrite it; and whether Readers are shown that a value was supplied. Each rule is carried by a requirement row that an accepted proposal applied.

## If it stays unknown

No metadata value is corrected by hand: a wrong value stays as recorded until a later release extracts the page again. Readers see no mark that a value was supplied.

## Evidence so far

On [[X-006]]'s 58 kept test pages 7 publication times were supplied by the date heuristic and no title or author was supplied; its design permits a model call to fill an empty title or date, which no run has measured. A copied value can be wrong too: on check S123 the page's declared metadata and the heuristic agree on a date the owner's label rejects. [[CP-001]] states what a supplied value gives up by not being a Judgement: a decision record, a Method version, a trigger, and a Curator's correction.
