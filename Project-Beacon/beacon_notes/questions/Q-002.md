# Q-002 Whether the evidence supports a trend

## What is unknown

Beyond the [[MIN_TREND_DEVELOPMENTS]] floor, how should BEACON decide whether the evidence supports a candidate trend?

## Why this priority

P1: an asserted trend gets quoted, and the trend work is about to start. It can proceed under the floor alone, so it is not P0; it is not P2, because Readers would see trends that meet only the floor.

## Answered when

A stated criterion, applied to a labelled set of at least 50 candidate trends, agrees with the labellers' supported or unsupported judgement on at least 90 per cent of them.

## If it stays unknown

A candidate trend that meets the [[MIN_TREND_DEVELOPMENTS]] floor, and whose constituent developments each trace to evidence ([[EVD-05]]), is asserted.
