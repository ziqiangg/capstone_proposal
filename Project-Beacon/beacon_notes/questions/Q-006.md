# Q-006 The initial Scope Criteria

## What is unknown

What rules should the Scope Criteria start with to decide whether an item concerns BEACON's subject area, cybersecurity with AI security included? They carry one rule already drafted with the genre vocabulary: work with no bearing on any security property is `OUT`, not `research`.

## Why this priority

P1: the scope Method is the first Judgement every item meets, and its work is about to start. It can proceed under the fallback below, so it is not P0; it is not P2, because the evaluation of the scope Method ([[REL-07]]) means nothing until the criteria it applies are written.

## Answered when

The rules are written, and two labellers applying them independently to at least 200 collected items agree on `IN`, `OUT` or `UNKNOWN` for at least 90 per cent of them.

## If it stays unknown

An English-language item that concerns cybersecurity, AI security included, is `IN`; work with no bearing on any security property is `OUT`; anything else is `UNKNOWN`, and so admitted ([[REL-02]]).
