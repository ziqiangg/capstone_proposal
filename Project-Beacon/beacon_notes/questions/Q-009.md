# Q-009 The approved mapping purposes

## What is unknown

What counts as an approved mapping purpose, and which purposes should the initial set hold?

## Why this priority

P1: every mapping starts with the decision whether it serves an approved purpose ([[CTX-04]]), and the mapping work is about to start. It can proceed under the fallback below, so it is not P0; it is not P2, because the fallback maps nearly every development.

## Answered when

Each purpose is stated with a test a mapping decision can apply, and two reviewers applying the set to at least 50 developments agree on whether mapping serves a purpose for at least 90 per cent of them.

## If it stays unknown

The set holds one purpose: a Reader can act on the development through a control or a threat-framework item. Every development with an evident security bearing is mapped.
