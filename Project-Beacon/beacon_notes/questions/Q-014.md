# Q-014 The same text from several sources

## What is unknown

When two sources carry substantially the same text, should BEACON treat them as one item or as two, and how should that change a development's count of distinct sources ([[DEV-08]]) and the agreement between its sources ([[DEV-05]])?

## Why this priority

P2: the fallback overstates corroboration, but it costs nothing yet, since no Reader-facing output exists. It is separate from [[Q-013]] because the development and assessment work acts on it, not the collection work.

## Answered when

On a sample of at least 200 developments, the rule's decisions about which items share a text agree with a labeller's on at least 95 per cent of item pairs, and the owner has ruled how a shared text counts toward distinct sources and agreement.

## If it stays unknown

Each is a separate item, and each source counts.
