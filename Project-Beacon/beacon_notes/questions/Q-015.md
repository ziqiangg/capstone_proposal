# Q-015 Export of BEACON's output

## What is unknown

## Why this priority

P2: nothing is blocked; the web interface and the Deliveries serve Readers meanwhile, and export is additive, so it can wait.

## Answered when

The owner names, for each output to be exported, the Readers' tools it must reach and the form those tools accept, or rules that there is no export.

## If it stays unknown

There is no export; Readers use the web interface and the Deliveries.
